stub. They describe the draft, with TinyLlama providing the tokenizer.

| Symbol | Value | Meaning |
| --- | ---: | --- |
| `V` | 32,000 | Vocabulary size |
| `D` | 512 | Model width |
| `L` | 6 | Pre-norm blocks |
| `H` | 8 | Self-attention heads |
| `d_h = D / H` | 64 | Head width, derived |
| `F` | 1,408 | SwiGLU hidden width |
| `T_max` | 1,024 | Context limit |

Project spec row 4 reconciles with four full-width attention projections,
three feed-forward projections, two RMSNorm scales per block, a final
RMSNorm scale, and one shared token matrix. Bias-free projections,
one K/V head per query head, and parameter-free RoPE reproduce the
approved budget.

| Component | Derivation | Parameters |
| --- | --- | ---: |
| Shared input/output token matrix | `V × D` | 16,384,000 |
| Q, K, V, and output projections per block | `4 × D × D` | 1,048,576 |

### Forward contract and proposed layer design

| Stage | Shape | Responsibility |
| --- | --- | --- |
| Input IDs | `[B, T]` | Unpadded integer token IDs with `1 <= T <= context_length`. |
| Token lookup | `[B, T, D]` | Read from the shared learned matrix `[V, D]`. |
| Q, K, V | Each `[B, H, T, d_h]` | Project separately, reshape into heads, and rotate Q and K. |
| Attention output | `[B, H, T, d_h]` → `[B, T, D]` | Use causal SDPA, merge heads, and apply the output projection. |
| SwiGLU | Two `[B, T, F]` projections → `[B, T, D]` | Apply SiLU to the gate, multiply by the up projection, then down-project. |
| Draft logits | `[B, T, V]` | Apply final RMSNorm and project using the same token weight. |

- **RMSNorm.** For each token vector `x`, compute
  `weight * x / sqrt(mean(x²) + eps)` over the last dimension. The
  learned weight is a length-`D` scale vector.
- **RoPE.** Use adjacent-channel pairs in each head. Apply a 2D rotation
  to pair `i` at position `p` with angle
  `p × rope_base^(-2i/d_h)`. Both Q and K use the same frequencies
  with their own positions. The dot product then depends on their
  relative position. Precompute cosine and sine through the context limit
  and keep them as nonpersistent buffers.
- **Causal self-attention.** For the uncached full sequence, Q and K have
  equal length. Use `F.scaled_dot_product_attention` with `is_causal=True`
  and dropout 0.0 so row `i` sees keys through `i`. Recombine heads before the
  `D → D` output projection.
- **Pre-norm and tied output.** Apply each normalization before its
  sublayer and add that sublayer's output to the residual stream. In
  order, use `x = x + attention(attn_norm(x))` and
  `x = x + swiglu(ffn_norm(x))`. Project final normalized states with
  `F.linear(hidden, token_embedding.weight)` so both uses share one
  parameter. The forward returns logits. The initial-loss check computes
  next-token cross-entropy from shifted labels outside the model.
- **Config.** Keep the existing dimension keys and tokenizer ID. Derive
  `head_dim` and validate positive integer dimensions, width divisibility
  by head count, even head width for RoPE, and finite positive RoPE and
  RMSNorm settings and the approved dropout. Report invalid YAML fields,
  input rank, and context length clearly. Verify tokenizer alignment
  separately so toy model tests can use a small vocabulary.

### Initialization

Initialize the shared token matrix and projection weights from a normal
distribution with mean 0 and standard deviation `init_std=0.02`. Use
`0.02 / sqrt(2L)` for the attention output and SwiGLU down projections
that write into the residual stream. Initialize each RMSNorm scale to one.
The tied projection uses the already initialized token matrix.

### Dev-approved specifications

- Set `rope_base=10000.0`, `rms_norm_eps=1e-6`, and `dropout=0.0` in
  the draft YAML. Adjacent-pair RoPE carries into cached decoding on Day 4.
- Use fixed-seed random tokens and require
  `abs(initial_loss - log(32000)) <= 0.5` nats. Record the measured loss
  and its deviation.
- Use bias-free attention and SwiGLU projections. Share a single weight
  between the input embeddings and output projection, and require exactly
  35,658,240 trainable parameters in the full configuration.

### CPU validation strategy — written before implementation

Reuse the repository's deterministic test seed `20261118` and isolate the
test RNG state. Use FP32 and a toy fixture with `V=32`, `D=16`, `L=2`,
`H=4`, `F=32`, and `T_max=16` for the layer and gradient tests. One
full-config smoke test uses a seeded synthetic sequence of nine token IDs
for eight input positions and shifted targets.

| Check | Acceptance criterion |
| --- | --- |
| Config and tokenizer | YAML loads with the locked dimensions and `head_dim=64`. Invalid dimensions and context lengths fail. The cached pinned tokenizer's vocabulary size, length, and ID range fit the draft embedding. |
| RMSNorm | Match an independently calculated last-axis RMS formula with nonuniform scale, including a zero input and a positive epsilon. |
| RoPE | Match a direct pair rotation. Shifting Q and K positions together preserves their dot product within FP32 test tolerance, and changing the relative offset changes it for the fixture. |
| Causal attention | Compare a tiny SDPA result with explicit lower-triangular masked attention. Perturb one input token and verify all earlier model logits agree within FP32 test tolerance and at least one logit at or after the perturbed position changes. |
| Count and initialization | Component counts reconcile to the table's unique total. Verify the standard deviations passed to the final model-specific initialization calls, including both residual projections, and check for unit RMSNorm scales. |
| Full-config logits and initial loss | The smoke test produces finite FP32 logits of shape `(1, 8, 32000)`. Fixed-seed random-token cross-entropy is finite and within 0.5 nats of `ln(32000)`. |
| Weight tying and backward | The shared matrix is the only trainable vocabulary projection weight. A change to an embedding row whose token is absent from the toy input changes its output logit. A toy next-token loss backpropagates finite gradients through the shared weight, attention, and SwiGLU. |
