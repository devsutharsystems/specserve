## Day 2 — Theory, frozen benchmark, and baselines

### Goal and success criteria

Learn the inference arithmetic and speculative-decoding theory, freeze a
benchmark of approximately 100 prompts from the roadmap's four categories, and
prepare Kaggle baseline runs without using the benchmark for training,
distillation, or tuning.

Success means:

- `bench/prompts.jsonl` is created from the UltraChat **test** split for chat
  Q&A plus copy-heavy summarization/extraction, code, and open-ended writing
  prompts as specified in the roadmap.
- Each record uses `max_new_tokens: 128`; every prompt plus 128 output tokens
  fits within the 1024-token context limit.
- The benchmark is frozen and committed.
- Kaggle scripts/runs cover plain greedy TinyLlama and prompt-lookup decoding
  on the frozen set, using the required timing protocol.
- Baseline results and environment versions are returned by Dev into
  `experiments/baseline/*.csv` and `experiments/env.txt`.

### Files to create or change

- Create and freeze `bench/prompts.jsonl`.
- Create the Kaggle baseline script/notebook required to run plain greedy
  TinyLlama and prompt-lookup decoding.
- Create `experiments/baseline/*.csv` from returned Kaggle results.
- Create `experiments/env.txt` from returned Kaggle environment information.
- Do not alter the frozen benchmark after committing it.
- Do not train, distill, or tune on benchmark prompts.

### Ordered task list

1. Learn Transformer Inference Arithmetic and sections 1–3 of Leviathan et
   al.; this is Dev's learning task.
2. Derive on paper the expected tokens per target pass:
   `(1 − α^(k+1)) / (1 − α)`; this derivation is Dev's task.
3. Construct the four-category benchmark, using only UltraChat **test** data
   for chat Q&A and adding the roadmap's copy-heavy, code, and open-ended
   writing categories.
4. Validate category membership, duplicates, tokenizer lengths, and the
   prompt-plus-output context bound before freezing.
5. Commit `bench/prompts.jsonl` and treat it as immutable.
6. Prepare Kaggle baseline execution that reads the frozen benchmark and
   records plain greedy and prompt-lookup results.
7. Run the required timing protocol: batch size 1, warmups,
   `torch.cuda.synchronize()` around timed regions, three repeats, and a
   recorded median and spread.
8. Bring the baseline CSVs and environment file back into the repository.
9. Verify the returned artifacts and report the measured results without
   inventing or rounding values.

### Kaggle needs

- Kaggle T4, 16 GB, with the frozen benchmark attached or obtained by cloning
  the public repository.
- Frozen `TinyLlama/TinyLlama-1.1B-Chat-v1.0` weights and tokenizer.
- Plain greedy TinyLlama and model-free prompt-lookup baseline execution.
- Environment capture for GPU, CUDA, PyTorch, and Transformers versions.
- Results downloaded back into `experiments/baseline/*.csv` and
  `experiments/env.txt`; results do not exist until Dev brings them back.

### Validation strategy (written before any code)

- Read every JSONL record and count records by each of the four categories;
  verify all four required categories are represented and record the total
  and per-category counts before freezing.
- Detect duplicate prompts both by exact prompt text and by duplicate record
  identity; any duplicate must be resolved before commit.
- Load the TinyLlama tokenizer and compute each prompt's token length.
  Verify `prompt_tokens + 128 <= 1024` for every record, and reject any
  record whose prompt alone exceeds the available context.
- Verify every record has `max_new_tokens` equal to 128 and uses the intended
  category/schema fields.
- Confirm chat Q&A records come from the UltraChat **test** split, not train,
  and keep the benchmark separate from any training or distillation input.
- For Kaggle results, verify batch size 1, warmups, CUDA synchronization,
  three repeats, recorded median/spread, and environment versions.
- Confirm baseline CSVs cover both plain greedy and prompt-lookup methods and
  that the benchmark commit is present before any baseline result is accepted.
